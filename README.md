# E-Commerce & Digital Storefront

A modern e-commerce storefront built with [Next.js](https://nextjs.org/), [Tailwind CSS](https://tailwindcss.com/), and [Google Sheets API integration](https://developers.google.com/sheets/api).

## Features

- ⚡ **Next.js 14** App Router
- 🎨 **Tailwind CSS** styling with high-converting e-commerce design
- 📊 **Dynamic Google Sheets Catalog Sync**
- 🛒 Instant Checkout & Cart management
- 📱 Responsive and mobile-first experience

## Getting Started

First, install the dependencies:

```bash
npm install
```

Run the development server:

```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser to see the result.

## Build for Production

```bash
npm run build
npm start
```
